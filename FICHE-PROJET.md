Fiche d'identité – Le Bon Pote

Outils : Claude (code), GitHub (sauvegarde), Vercel (mise en ligne), Supabase (données)

1. Pour qui : les étudiants du campus de l'ESP.
2. Quel problème : aujourd'hui, les étudiants ne savent pas qui sait faire quoi sur le campus (photo, vidéo, dev), ni à qui demander une coloc ou un covoiturage.
3. Les 4 écrans : les annonces, la demande de contact, la messagerie entre étudiants qui se sont acceptés, mon profil créé depuis mon CV.
4. Ce qu'on ne fait pas : pas de paiement, pas d'appli à installer, pas de coordonnées visibles avant l'accord de la personne.
5. Ce que l'IA ne touche jamais : cette fiche, les fichiers que je n'ai pas cités, et aucune clé ni aucun mot de passe dans le code.

2e fonctionnalité IA – L'annonce rédigée par l'IA

À quoi elle sert : j'écris quelques mots (ex. « photo soirée asso »), l'IA propose un titre et une description claire pour mon annonce. Je relis, je corrige si besoin, puis je publie.

Pour qui : tout étudiant qui publie une annonce et ne sait pas comment la formuler.

Comment la tester : je tape « covoit Lyon vendredi », l'IA remplit le titre et la description ; je peux les modifier avant de publier ; rien n'est publié sans mon clic sur « Publier ».
